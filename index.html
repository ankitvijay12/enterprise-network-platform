Platform Architecture & Simulation Engine

Backend Engine Online • FastAPI 3.11 + NetworkX Graph Theory

NetSphere is an enterprise-grade platform for designing, planning, and stress-testing complex network topologies (Campus, Spine-Leaf Data Center, and WAN Branch). All simulations are executed through a Python graph-theoretic simulation engine.

Dynamic Dijkstra Routing

Calculates optimal shortest paths across topology weighted by OSPF link cost, latency (ms), or hop count with automated cycle detection and bottleneck identification.

Failure Outage & Cut Recovery

Simulates hardware failures and fiber cuts. Evaluates partition isolation, detects orphaned nodes, and calculates automated failover rerouting paths.

M/M/1 Traffic Queuing Load

Models enterprise traffic flows using M/M/1 queue models. Identifies congested links (>80% utilization) and computes queuing delay degradation under load.

Tarjan SPOF Redundancy

Executes Tarjan's biconnectivity depth-first search in linear O(V + E) time to identify single points of failure (articulation nodes and bridge links).

VLSM Subnet Planning (IPAM)

Allocates major network address blocks via recursive binary prefix partitioning, maximizing address efficiency with zero wasted host ranges.

Architecture Validation Engine

Automated design rule checker auditing MTU/speed matching, default gateway reachability, tier hierarchy integrity, and single-attached critical hosts.
